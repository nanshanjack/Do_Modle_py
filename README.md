## 核心结论

### 1. 回测地基已实证可信

| 验证项 | 结果 |
|---|---|
| 全区间 B&H 独立校验（2016–2026，2591 交易日，13 次分红） | **残差 −0.0000** |
| 分红与送转 | **由脚本独立重算，与引擎完全一致** |
| akquant 第三方对账 | **无不一致项** |
| 单测 | **951 passed** |

### 2. 因子研究：78 因子 + 8 择时信号，**全部未通过门槛**

| 信息源 | 数量 | 评估方法 | 最好 \|IC_IR\| | 通过 |
|---|---|---|---|---|
| 价格 / 量能 | 47 | 截面 IC | 0.133 | ❌ |
| 估值（PE/PB/PS/PCF/换手） | 11 | 截面 IC | 0.133 | ❌ |
| 业绩预告 | 5 | 截面 IC | 不可评估（事件太少） | ❌ |
| 财务质量（ROE/毛利/成长/杠杆） | 8 | 报告期采样 | 0.335 | ❌ |
| **运价择时信号** | **8** | **分层择时** | — | ❌ |

**门槛设计**（三重闸，缺一不可）：

1. **全空间 Bonferroni**：校正基数 = **实际候选数**（k=78 → z=3.413）
2. **Walk-Forward 稳定**：每个滚动窗口都要过，且符号一致率 ≥ 80%
3. **经济意义**：`|IC_IR| ≥ 0.3`

> **为什么不做"挑最好的那个"**：k 个候选里挑 IC_IR 最大，纯噪声下
> 至少一个"显著"（p<0.05）的概率 = `1 − 0.95^k`，**k=78 时 = 98%**。
> 所以本项目**只做过滤，不做挑选**，排序用 **maximin（按最差窗口）**。

### 2b. 端到端验证：因子**能不能变成正收益**（P6-g）

IC 显著 ≠ 能赚钱。IC 不涉及成本 / T+1 / 涨跌停 / 手数 / **要交易多少次**。
所以又跑了一遍**穿过完整引擎**的回测（78 因子 × 2 方向 = 156 次）：

| 层 | 结果 |
|---|---|
| 基准 B&H（同引擎同成本） | 200,000 → **751,526（+275.76%）**，年化 +13.28% |
| 样本外**跑赢 B&H** | **5 / 78（6.4%）** |
| 毛收益 vs 含成本跑赢数 | **10/78 → 5/78**（成本拖累 102~146 个百分点） |
| 安慰剂检验（仓位循环移位 ×100） | 最好 p = 0.030 / 0.040，门槛 **0.00064** → **不通过** |

**三个关键机制发现**：

1. **成本是决定性约束** —— 反转类因子（IC 最强）毛超额 **+96.95%**，
   被 237 笔交易的 **10.2 万元**成本吃成 **−5.09%**。**信号方向对，是换手成本吃干净的。**
2. **5 个"样本外赢家"里 3 个只有 1 笔交易** —— 本质是「B&H 晚入场」。
   安慰剂 **p = 1.000**（100 次随机移位结果完全相同）→ **零预测力**
3. **全期净值排名是陷阱** —— 最高 **+638%** 是"事后挑方向"造出来的，
   前 20 名里多数方向与训练段结论**相反**

详见 [`P6g_因子端到端回测结论.md`](P6g_因子端到端回测结论.md)。

### 3. 为什么都不显著：三重约束相乘

| 约束 | 具体 |
|---|---|
| **截面 N 太小** | 航运板块平均 N=8.7 → IC 估计噪声 **0.36**（N=100 时仅 0.10） |
| **有效样本少** | 日频 T=2500 但自相关 0.68 → 有效 620；报告期 T 仅 35 |
| **信号本身弱** | 最好因子真实 IC ≈ 0.056，而可用门槛（N=8.7）对应 IC ≈ 0.108 |

### 4. 有价值的否定性发现

| 发现 | 说明 |
|---|---|
| **航运板块是反转板块** | 动量因子 IC 全为负（`mom_20/60/120`、`ma_gap_20`） |
| **业绩预告"利好出尽"** | `fc_score` IC = −0.099：预增公告后股价反而跌 |
| **财务数据是周期股的反向指标** | 8 个质量因子 IC 全为负 —— 周期高点财务最漂亮，但那时正该卖 |
| **运价暴涨短期利空、中期利好** | BDTI +5% 后 20 日超额 −2.62%，60 日转正 +4.44%（t=1.62 不显著） |
| **运价信号尾部风险大** | 收益负偏度：18% 事件亏超 10%，最差 −26.5% |

## 方法论：本项目踩过的坑

这些都是**真实的、花了代价才发现的**问题，记录下来避免重犯。

### 1. 前向收益窗口重叠 → t 值虚高 2 倍

**问题**：5 日前向收益下，相邻两日的 IC 有 4/5 的收益区间重叠 → IC 序列自相关
（实测 lag-1 = **0.68**）→ 朴素 `t = IC_IR × √T` **系统性高估约 2 倍**。

**修正**：`T_eff = T/(1+2Σρ_k)`（Bartlett 截断），`t = IC_IR × √T_eff`。

**影响**：修正后「① t 过 Bonferroni」从 **25/63 → 0/63**。

### 2. 季度/事件因子必须按报告期采样

**问题**：财报因子值在两次公告之间**完全不变**。按日频算 IC 等于把同一份财报
重复计入约 60 次 → 自相关 > 0.95 → t 值虚高 10 倍以上。

**修正**：`xsec.build_report_sections()` —— 每标的每季**只取一个观测**。

### 3. 全行业共同指标不能用截面 IC

**问题**：运价指数（BDTI/BDI/…）同一天所有标的值**完全相同** → 截面零变异 → 截面 IC 恒为 `nan`。

**根因**：阶段一是**单标的择时**，我却一直用**选股**的方法评估。

**修正**：新增 `evaluation/timing.py`（分层择时 + 事件研究）。

**同类信号**：运价指数、宏观指标、日历季节性、地缘事件。

### 4. 滑点在低价股上被 tick 取整吃掉

**问题**：6.08 元 × 0.05% = 0.00304 元 < 半个 tick（0.005）→ 取整后归零。

**修正**：`slippage > 0` 时成交价**至少移动 1 tick**。
副作用：低价股上滑点被放大（3.30 元时 ≈6 倍），但这是**更真实**的 tick 量化。

### 5. 公司行为的顺序反了（真 bug）

**问题**：`CorporateActionHandler` 原来**先送转、再按送转后股数派息** → 分红基数被放大。

**发现方式**：全区间校验用**脚本独立重算**分红与送转，发现 13 次除权累计**多派 24.80 元**。

**修正**：**先按登记日持仓派息、再送转**。

> **教训**：不能读引擎自己的输出做校验 —— 必须独立重算。

### 6. 静默失败比报错更危险

**问题**：财务抓取脚本把**表名**传给 `getattr(bs, ...)` → 全部返回 `None` →
**3168 个任务 2 秒空转，却报告"无失败"**。

**修正**：修接口名映射 + **新增"跑了任务却取回 0 行即 FAIL"校验**。

### 7. 文档里的"硬限制"结论也需验证

**问题**：设计文档曾断言「akshare 没有 BDTI（原油运输指数）」并据此排除运价数据。
**实际核查源码发现 `macro_china_bdti_index()` 存在**，有 **25 年历史**。

**教训**：文档结论也必须有**验证日期和证据**，不能当作事实传递。

### PIT（防前视）规则

| 数据 | 可见时点 | 依据 |

| 分红送转 | 除权日 09:00 | 盘前公布 |

> 确认 baostock 按**财报公布日**更新，PIT 安全。
