### 方法论反思（**本轮最重要的分析**）

**门槛是否过严？** 推导：

```
Spearman IC 的零假设标准误 ≈ 1/√(N−1)
IC_IR = mean(IC)/std(IC) ≈ ρ × √(N−1)
```

| N | √(N−1) | IC_IR=0.3 ⟺ 真实 ρ |
|---|---|---|
| **8.7** | **2.77** | **0.108** |
| 20 | 4.36 | 0.069 |
| 100 | 9.95 | 0.030 |

→ **N=8.7 时 `IC_IR≥0.3` 恰好等价于经典「IC≥0.1」门槛（Grinold-Kahn）**
→ **门槛标定正确，不是过严**

**实测验证**：`std_IC≈0.44` vs 理论 `1/√7.7=0.36`（同量级 ✓）；
最好因子 `|mean_IC|=0.056` → 真实 ρ≈0.056 **< 门槛 0.108**。

**结论：不是门槛苛刻，是信号强度不足。**

### 方法纪律：为什么必须 split-half

用**全期** IC 挑因子再在全期评估 = 过拟合。正确做法：**A 段选因子+定符号 → B 段评估**，反向再做一次。
符号由训练段决定（`sign = +1 if IC_IR_train > 0 else −1`），**不能事后按测试段调**。

接入运价因子后跑截面 IC，**平均 N = 0.0，全部 nan**。

**根因**：实测 2016-01-05 六只标的的 BDTI **都是 869.0**，截面取值个数 = **1**。
→ **运价是全行业共同指标 → 截面零变异 → 截面 IC 恒为 nan**

**这暴露了一个更根本的框架问题**：

| 问题 | 正确方法 |
|---|---|
| "哪些股票未来会涨"（选股） | 截面 IC |
| **"现在该不该持有 601872"（择时）** | **分层回测** |

**阶段一是单标的择时，我却一直用选股的方法评估。**

**同类信号**（都不能做截面因子）：运价指数、宏观指标、日历季节性、霍尔木兹通航量。

**这回头解释了为什么"BDTI 无预测力"的历史结论可疑 —— 它可能从来没被用正确的方法评估过。**

### 新增：分层择时评估

`do_modle/evaluation/timing.py` → `quantile_timing()`
- 按信号分位分组（默认 5 档）→ 比较各组未来 N 日收益
- 检验**单调性** + 顶底差显著性
- **不重叠采样**（每 horizon 日取 1 个观测）消除重叠窗口自相关

**单调性比 t 值更重要** —— 择时信号若无单调性，顶底差再大也是噪声。

### 择时评估结果：8 个信号 0 个通过

**"BDTI 无预测力"现在有了更可信的依据** —— 之前方法一直错，现在用正确方法验证，结论依然否定。
