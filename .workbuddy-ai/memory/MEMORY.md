## 交易成本（用户 2026-09-17 明确要求牢记）

| 项 | 值 | 说明 |
|---|---|---|
| 佣金率 | **万分之一（0.0001）** | 用户 2026-09-17 修正（先前记的万五是错的） |
| 最低佣金 | **0.0（免五）** | **不存在最低 5 元，无单笔金额临界点** |
| 印花税 | 0.0005 | 仅卖出 |
| 过户费 | 0.00001 | 双边 |
| 滑点 | 0.0005（0.05%），**且至少 1 tick** | 模型 B，用户 2026-09-17 选定 |

→ **往返成本率（不含滑点）= 0.0001×2 + 0.0005 + 0.00001×2 = 0.072%**
→ 含滑点 → **≈ 0.172%**

**滑点模型 B（已定稿）**：`slippage > 0` 时成交价至少移动 1 tick。
理由：A股报价以 0.01 元为最小单位，低价股上百分比滑点小于 1 tick 时**物理上不可实现**；
纯取整会把滑点抹成 0（实测 4.88 元 → 0.00244 元 < 半 tick），导致回测系统性低估成本。
**副作用**：低价股上滑点被放大（3.30 元时 1 tick ≈ 0.303% ≈ 6 倍）。**交叉点 = 20 元**。
这是**更真实**的 tick 量化，非纯保守。需要对照时用 `CostConfig(slippage=0.0)`。
